Small structure constructor inlining, 2026-10-28

Base: a06ac410, with the cached structure layout slot read already installed.
Small standard keyword constructors now default to INLINE. Calls with known
keywords avoid temporary argument-list construction and repeated scanning.
Local NOTINLINE still forces an ordinary call. Large constructors and BOA
constructors keep their previous policy.

Compiler inlining now retains the named call when its arguments cannot match
the known lambda list. Previously it embedded a copy of the old function even
when lambda lifting declined the call. The structure-layout regression exposed
this with a call using :ADDED, compiled before redefinition introduced that
slot. Retaining the named call lets it reach the rebuilt constructor.

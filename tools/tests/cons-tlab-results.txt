Cons TLAB experiment, 2026-10-26
Branch: feature/cons-tlabs; baseline allocator: 68b7e85c

One live x86-64 KVM guest, one vCPU pinned to host CPU 4.
Host: AMD Ryzen 5 3600. Timings are elapsed TSC ticks, not core cycles.
Native compile-file and wired LLF loading through the serial REPL:
  runtime/runtime-x86-64.lisp -> runtime/allocate.lisp -> system/gc.lisp
  -> shared baseline under separate names -> benchmark callers.

Each pair measures 500000 (cons nil nil) calls in each mode, with 16 calls
per loop iteration. Shared/TLAB order alternates. Compilation, explicit GC,
young-area expansion and page touching, warmup, and validation are excluded.
Normal CONS counters and TLAB refills are included. Every sample checked
8000000 per-thread allocation bytes, a valid returned cons, and zero timed GC.
